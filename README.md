# Principles of Marketing (AI Plus One)

## About the book

This compact rough draft teaches beginning marketing readers how to build a testable offer with basic numeracy and no platform training. Follow a fictional tool library considering a portable bicycle repair kit. You will identify a reachable segment, write a promise backed by evidence, reconcile the fee with capacity and customer effort, and use a rollout funnel to decide what to change. No spreadsheet, ad account or AI subscription is required.

## Start reading

Start with [Find the borrowing problem](chapters/01-find-the-borrowing-problem.md) or use the [complete chapter guide](#chapter-guide). Read the Markdown on GitHub or download the repository for offline use. No separate formatted book edition is included.

## Chapter guide

### Part I · Choose a customer and a promise

1. [Find the borrowing problem](chapters/01-find-the-borrowing-problem.md): Turn small interviews into segment hypotheses without inventing demand.
2. [Make a promise you can check](chapters/02-make-a-promise-you-can-check.md): Choose a target and position an offer against a substitute with evidence for each claim.

### Part II · Deliver and measure the offer

3. [Price the whole exchange](chapters/03-price-the-whole-exchange.md): Compare contribution and capacity while accounting for the borrower's time and effort.
4. [Choose a channel you can test](chapters/04-choose-a-channel-you-can-test.md): Set up a meaningful comparison with permission, access, and comparable availability.
5. [Follow the funnel to fulfillment](chapters/05-follow-the-funnel-to-fulfillment.md): Track what changes between contact, request, pickup, and repeat use without claiming causality.

## How to teach or study it

Start with the people and the task before writing copy. Write a promise that the service can keep before choosing a fee or channel. The [independent pilot brief](practice/pilot-brief.md) tests whether the pieces form a plan a reviewer can reproduce. Make an unaided first draft, then compare it to the [worked review](practice/pilot-key.md). The [queue blueprint](https://github.com/nikbearbrown/ai-plus-one-paper/blob/main/book-queue/editorial-blueprints/17-principles-of-marketing-ai-one.md) describes a proposed approach, not an adopted syllabus.
